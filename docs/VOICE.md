# Голосовые сообщения

Отправьте боту голосовое на русском длительностью до 60 секунд (до 8 МБ).
Он покажет расшифровку и обработает её как обычный текст. Создание, перенос
и удаление встречи по-прежнему требуют кнопки: проверьте название, дату и время.
Ошибки распознавания возможны, особенно в именах и числах.

## Как работает

1. Проверка владельца выполняется до скачивания.
2. Telegram-запись скачивается во временный каталог.
3. Отдельный процесс запускает faster-whisper, модель base, CPU/int8.
4. На распознавание отводится 120 секунд. При превышении процесс завершается.
5. Аудиофайл удаляется при завершении обработки, включая обычные ошибки.
6. Расшифровка передаётся существующему агенту; его ответ сохраняется в истории.

Распознавание не использует платный API и не отправляет запись провайдеру модели.
Само сообщение уже хранится в Telegram; его удаление ботом из чата не выполняется.
Распознанный текст, как обычный запрос, передаётся в OpenRouter и может сохраняться
в PostgreSQL как часть истории. Голосовые файлы в БД не сохраняются.

Модель загружается в процесс для каждой записи: это проще и ограничивает время
жизни потребляемой памяти, но добавляет задержку. Текстовые запросы не требуют
Whisper. Для озвучивания ответов (text-to-speech) эта версия не предназначена.

## Запуск на новом компьютере

```powershell
docker compose build bot
docker compose run --rm --no-deps bot /app/.venv/bin/python -m app.voice_worker --download
docker compose up -d
```

Для первой загрузки нужен интернет и доступ к Hugging Face. Веса сохраняются
в volume whisper_models и переживают пересоздание контейнера.
При обычном распознавании используется только локальный кэш весов.
Не удаляйте volume, если не хотите скачивать модель повторно.

Используется [faster-whisper](https://github.com/SYSTRAN/faster-whisper):
декодирование обеспечивается PyAV, отдельный системный FFmpeg не нужен.
