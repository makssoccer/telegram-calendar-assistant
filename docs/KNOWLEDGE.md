# Загрузка материалов в базу знаний

Первая версия принимает текст, TXT и Markdown в UTF-8. Материалы привязаны к одному
из восьми мест Гродно. Загрузка и подтверждение обходятся без ИИ и новых API-ключей.

## Пример

Самый простой способ: отправь **`/learn` без аргументов**. Бот спросит по очереди:

1. Место — выбери кнопку или напиши следующим сообщением «Старый замок».
2. Короткое название материала — например «История Старого замка».
3. Источник — только URL либо краткое название книги/статьи. Не вставляй сюда текст статьи.
4. Сам текст — отдельным сообщением или файлом TXT/MD.

Затем нажми «Добавить». Пока бот ждёт место, работают также `/place Старый замок`
и `/places old_castle`. Допустимы русские названия и ID. Вне этого шага `/places`
показывает справочник. Можно начать сразу с `/learn Старый замок`.

Старый сокращённый формат также поддерживается:

1. Отправь боту команду:
   ```text
   /learn old_castle | История Старого замка | Название книги, автор, страница или URL статьи
   ```
2. Следующим сообщением отправь сам текст или файл `.txt` / `.md`.
3. Бот покажет место, источник, начало текста и количество фрагментов.
4. Нажми «Добавить». Только после этого материал участвует в поиске.
5. Задай вопрос о факте из материала, например: «Расскажи про Старый замок и его перестройки».

Можно прикрепить файл сразу с командой `/learn ...` в подписи.
Названия и источники указываются вручную; бот не скачивает страницы по URL.
Источник — ссылка либо библиографическое описание, а не гарантия достоверности.
Не отправляй пример-заглушку как настоящую историческую информацию.

## Команды

- `/learn` — инструкция. Формат: `/learn place_id | Название | Источник`.
- `/places` — ID мест: `station`, `university`, `gilibert_park`, `lenin_square`,
  `soviet_square`, `drama_theatre`, `old_castle`, `new_castle`.
- `/cancel_material` — отмена текущей загрузки или неподтверждённого черновика.
- `/materials` — первые десять добавленных материалов, кнопки удаления.
- `/materials 2` — следующая страница. Удаление требует второго подтверждения.

Пока бот ждёт материал, следующий обычный текст считается содержимым документа.
Для возврата к беседе используй `/cancel_material`. Команды календаря продолжают работать.
Новая команда `/learn` заменяет предыдущий неподтверждённый черновик.

## Ограничения и хранение

До 100 КБ на файл, от 40 до 20 000 символов, до 100 подтверждённых материалов владельца.
PDF, DOCX, изображения и распознавание сканов пока не поддерживаются.
Черновик действует 30 минут с начала загрузки, состояние сохраняется при перезапуске.
Просроченные черновики очищаются при проверке ожидаемой загрузки.
Одинаковый текст для одного места не добавляется повторно; пробельные различия игнорируются.
Удаление убирает документ и его фрагменты из поиска, но не стирает ранее отправленные
сообщения и историю диалога. `/reset` очищает историю, а не базу знаний.

Текст и источник хранятся в локальном PostgreSQL. Файлы скачиваются в ограниченный
буфер памяти; имя файла не используется как путь. При ответе на вопрос выбранные
фрагменты передаются облачной модели через OpenRouter. Сама загрузка LLM не вызывает.

## Устройство для изучения

`app/knowledge_telegram.py` обрабатывает команды, файлы и кнопки.
`app/knowledge.py` содержит нормализацию, разбиение текста и KnowledgeStore — аналог
сервиса/репозитория в Java. Миграция `0007` создаёт таблицу `knowledge_documents`.

Состояния: `awaiting` (ждём текст) → `review` (ждём кнопку) → `active` (доступно поиску).
Переход к active выполняется транзакционно. Блокировка по владельцу, хеш содержимого
и уникальный индекс защищают от дублирования. Для каждого запроса БД проверяется owner_id.

Фрагменты размером до 1000 символов имеют перекрытие около 100 символов. По возможности
граница проходит по строке, предложению или слову. В базе сохраняются оригинальный
нормализованный текст, фрагменты, заголовок, источник, место, хеш и дата загрузки.

`StoryRetriever.retrieve_async()` объединяет встроенные карточки с подтверждёнными
фрагментами владельца для выбранного места и ранжирует их лексически. В модель уходят
максимум три фрагмента. В ответе для загрузок указывается материал пользователя,
короткий ID, номер фрагмента и предоставленный источник. Наличие ссылки не доказывает
истинность текста; модель получает инструкцию не исполнять команды из документов.

Этот этап — приём материалов и подключение их к существующему RAG. Embeddings,
векторный/гибридный поиск и классификация через Jev ещё не добавлены.

## Обновление

```powershell
docker compose up -d --build --no-deps bot
```

Миграция применяется при старте. Дополнительных переменных окружения не требуется.
